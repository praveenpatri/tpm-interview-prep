# TPM Interview Frameworks

Pick 1-2 per round. Apply them properly, don't just name them.

| Framework | Use it for | Core idea |
|-----------|-----------|-----------|
| **STAR** | Behavioral questions | Situation, Task, Action, Result. Spend most of the time on Action and Result. |
| **SPADE** | Decision-making questions | Setting, People, Alternatives, Decide, Explain. Shows structured decisions. |
| **DACI** | Ownership and decision rights | Driver, Approver, Contributors, Informed. Resolves "who decides". |
| **RACI** | Cross-team execution | Responsible, Accountable, Consulted, Informed. Clarifies roles on a program. |
| **CIRCLES** | Product-flavored TPM questions | Comprehend, Identify, Report, Cut, List, Evaluate, Summarize. |
| **5 Whys** | Root cause and postmortems | Ask why repeatedly until you reach a systemic cause, not a person. |
| **RICE** | Prioritization | Reach, Impact, Confidence, Effort score. |
| **MoSCoW** | Scope negotiation | Must, Should, Could, Won't. Useful for trimming scope against a deadline. |
| **OKR framing** | Goal setting and alignment | Objective plus measurable key results tied to outcomes. |
| **Eisenhower matrix** | Time and priority triage | Urgent vs. important quadrants. |
| **PRD structure** | Requirements and spec questions | Problem, goals, non-goals, users, requirements, metrics, risks, open questions. |
| **Pre-mortem** | Risk questions | Assume the program failed, list why, then mitigate up front. |
| **Estimation (top-down / bottom-up)** | Sizing questions | State assumptions, split the problem, sanity-check against known anchors. |

## Typical round themes (adapt to the company)

- **Recruiter / HM screen:** motivation, scope, level fit, program highlights
- **Program execution:** planning, risk, scope, deadlines, dependency management
- **Technical depth / system design:** architecture fluency, tradeoffs, debugging a delivery problem
- **Behavioral / leadership:** influence without authority, conflict, failure, ownership
- **Cross-functional / stakeholder:** communicating with executives and partner orgs
- **Bar raiser / values:** company principles, judgment, raising the bar
